**🛰️ GeoNLI — Satellite Imagery VLM**

Inter IIT Tech Meet 14.0 · ISRO VLM Challenge

**💧 Groundwater Reconstruction**

*Published · Scientific Data (Nature Portfolio) · IIT Gandhinagar*

Two-stage pipeline — QRF gap-filling with K-means clustering, then Chow-Lin temporal disaggregation — rebuilding monthly water levels (1996–2021) for 4,514 Indian wells. R² = 0.84, RMSE = 1.59 m; validated on 333 U.S. wells.

📄 [Read the published paper](https://www.nature.com/articles/s41597-026-08089-z)

</td>
</tr>

**🔧 PCB Defect Detection (AODNN)**

*Under review, IEEE Transactions*

Faster R-CNN + VGG16 backbone with saliency-based orthogonal regularization on ROI heads and a Frobenius-norm hybrid loss — pushing feature diversity without the DenseNet-scale parameter count. 87.2% accuracy across six defect classes.
